# 小游戏大厅

浏览器里直接玩的小游戏合集。打开 `index.html`（或 GitHub Pages 链接）进入大厅，点哪个玩哪个。纯静态文件，无需构建、无需登录。

```
index.html          游戏大厅（首页）
mota/index.html     魔塔 · 五界（说明见 mota/README.md）
td/index.html       守卫前线（塔防）
survivor/index.html 怪潮求生（割草闯关）
craft/index.html    方块拓荒（2D 沙盒）
shared/monsters.js  15 种怪物的绘制库，新游戏共用
*/cover.jpg         大厅卡片用的封面截图
update.js           自动更新检查（三个页面共用）
```

| 游戏 | 简介 |

## 方块拓荒

参考泰拉瑞亚做的 2D 横版沙盒：像素贴图、圆角拼接的地形、远景山林、昼夜和洞穴光照。

- **手机**：左摇杆移动（往上推是跳，往下推穿过平台），右摇杆朝哪推就往哪用手里的东西——拿镐挖、拿方块放、拿剑砍，准星会自动贴到那个方向最近的方块上；也可以直接点屏幕上的格子。右下还有单独的跳跃键，按得久跳得高。
- **电脑**：A/D 移动，W/空格跳，S 穿过平台；鼠标指哪用哪，按住连续用；数字键或滚轮切换物品栏，E 开背包，Esc 菜单。
- **物品栏和背包**：左上角 10 格物品栏，背包共 40 格（第一行就是物品栏）。点一格拿起，再点另一格放下或交换；「丢弃」删掉拿起的物品。
- **挖到的东西会掉在地上**，走近自动吸过来。砍树只要挖树干，整棵倒下掉原木。
- **合成**：在背包里，能做的排在前面。后面的配方要站在工作台或熔炉旁边。镐分木 / 石 / 铁 / 金四级，铁矿要石镐，金矿和水晶要铁镐。
- **走路**会自动迈上一格高的台阶，不用每格都跳。
- 夜里和没有光的洞里会出怪，放火把就不刷。床可以设重生点、夜里睡到天亮。菜单里可以切创造模式（物品无限、秒挖、能飞、没有怪）。
- 世界每 8 秒和切到后台时自动存档；旧版存档会自动转成新的背包格式。

## 怪潮求生

角色自动攻击，手机按住屏幕拖动走位，电脑用 WASD。升级时三选一（6 种武器、6 种被动）。

- **关卡**：5 张地图，各有自己的障碍布局——林间空地（树和池塘）、流沙遗迹（断墙废墟）、幽暗矿洞（巨石通道）、亡者墓园（墓碑和栅栏）、熔岩王座（石柱和岩浆池）。撑到倒计时结束出首领，打倒过关并解锁下一张。每关都从 1 级开始。
- **小地图**：右上角，白点是自己，红点是怪，黄点是道具，大红点是首领，白框是当前视野。
- **地图道具**：旋刃风暴（多 3 把旋刃 15 秒）、疾风（移速 +50%）、狂暴（冷却 -40%）、护盾（无敌 6 秒）、磁铁、炸弹、药水、宝箱。每 13 秒刷一个，场上最多 5 个。
- **金币与商店**：怪物掉金币，过关有奖励（首次翻倍），输了也能带走。在关卡选择页买永久强化：体质、锋利、轻盈、随身旋刃、护甲、引力、贪婪、复活。
- 对局自动存档，退出重开回到原来的关卡、位置和等级（场上的怪物清空）。

## 守卫前线

选塔 → 点空地放置 → 点「开始下一波」。电脑上鼠标悬停就能看到射程；触屏上第一下只显示预览和射程，再点同一格才放置。怪物走到城堡扣生命，归零失败；满血通关三星。每个主题第一关默认解锁，其余需通关上一关。

| 守卫 | 价格 | 特点 |
|---|---|---|
| 弓箭塔 | 50 | 射速快、单体 |
| 火炮塔 | 90 | 范围爆炸 |
| 冰晶塔 | 70 | 范围减速 |
| 雷电塔 | 130 | 连锁闪电、无视护甲 |

塔可升到 3 级（伤害 ×1.7 / ×2.8，射程 +0.25 格/级），出售返还 60%。弓箭塔 2 / 3 级有 15% / 25% 暴击（双倍伤害）。选中塔后可切换攻击目标：最前 / 最强 / 最弱。

技能（各自冷却，开局即可用）：

| 技能 | 冷却 | 效果 |
|---|---|---|
| 火雨 Q | 32 秒 | 点地图落下 6 颗陨石，范围伤害，无视护甲，伤害随波次提高 |
| 冰封 W | 48 秒 | 冻结全场怪物 4 秒（首领改为减速 60%、持续 3 秒） |

界面会按屏幕自适应：手机竖屏时地图自动转成竖向（9×14），手机横屏时状态栏和塔分列左右两侧，平板和电脑用上下布局；对局中旋转屏幕不会打断游戏。

顶栏还有「自动」（清场后自动开下一波）和「音效」开关。快捷键：1–4 选塔，Q / W 技能，空格开波，P 暂停，Esc 取消。

### 无尽模式

每个主题的关卡列表最后有一张无尽地图（∞），波数无限，记录最高守住的波数。

- **怪物**：生命、速度、护甲随波次提高，第 30 波封顶（生命约 50 倍、速度 +30%、护甲 +5）。封顶后只增加数量和出怪密度，每 5 波出首领。
- **永久强化**（底栏「强化」按钮，对全部塔生效，有上限）：攻击 +10%/级 ×10、攻速 +6%/级 ×10、射程 +4%/级 ×5，价格逐级上涨。
- **清除障碍**：点地图上的树、石头等障碍，花金币清掉后可以放塔；每清一个贵 30。
- **消耗品**（不封顶）：修复城堡（生命 +1）、战鼓（全部塔攻速 +50% 持续 10 秒）、技能充能（冷却中点技能按钮直接买）。同一波内每用一次涨价 50%，下一波恢复。
- 一发炮弹最多炸 8 个、一发冰弹最多冻 12 个（所有模式都生效），否则怪越密范围塔越强，无尽模式永远打不穿。

## 如何新增

- **新游戏**：放到 `<名字>/index.html`，再放一张实机截图 `cover.jpg`（约 16:10），然后在首页 `index.html` 的 `GAMES` 数组里加一项（名称、路径、封面、简介）。
- **塔防新关卡**：在 `td/index.html` 的 `LEVELS` 里加一项（主题、路径折线、波数、生命倍率、初始金币）。
- **塔防新主题**：在 `THEMES` 里加一项（配色、装饰、五种怪物的名字和颜色）。

## 存档

退出后重新打开会回到上次的状态：魔塔每 10 秒和切到后台时自动存档，打开即读取最新存档；塔防对局（塔、怪物、金币、波次、技能冷却）每 1.5 秒和切到后台时保存，重新打开直接回到那一局并暂停，点一下地图继续；通关、失败或主动点「选关」退出后这份对局存档会清掉。大厅会标出上次在玩的游戏。

所有游戏的进度都在浏览器 localStorage 里。魔塔搬到 `mota/` 后存档键没变，同一域名下原有存档继续有效。

## 更新

每个页面末尾都引用了 `update.js`：打开或切回页面时会向服务器取一次最新页面，和正在运行的比对，不同就换成新版。大厅和塔防选关页直接刷新；魔塔和塔防对局中只弹出「有新版本」的提示，由玩家决定何时更新。这主要是为了添加到手机主屏幕的书签——那种独立窗口没有刷新按钮。更新不影响存档。新增游戏页面时在 `</body>` 前加一行 `<script src="../update.js"></script>` 即可。
